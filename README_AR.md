# GeoCadastre — Touahria Radhwane

## تشغيل التطبيق
- افتح `index.html` مباشرة بواسطة Chrome أو Edge. لا تحتاج إلى Python أو Flask أو ملفات BAT.
- ملفات التصميم والبرمجة موجودة داخل `assets/css` و`assets/js`.
- البيانات تحفظ محلياً في المتصفح تلقائياً (LocalStorage).

## ملف Excel الدائم
1. افتح التطبيق بواسطة Chrome أو Edge على الحاسوب.
2. اضغط «Lier mon fichier Excel» واختر مكان إنشاء `GeoCadastre_Data.xlsx` داخل مجلد `Data` في المشروع.
3. وافق على صلاحية الوصول للملف. عندئذ يحاول التطبيق تحديث ملف Excel مع كل إضافة أو تعديل.
4. إذا لم يدعم المتصفح الربط المباشر، استخدم «Exporter Excel» لتنزيل نسخة، ثم استعمل «Importer Excel» لاستعادتها أو دمجها لاحقاً.

## ملاحظة مهمة حول الحفظ
صفحة HTML ثابتة لا تستطيع الكتابة بصمت إلى أي ملف على القرص؛ المتصفح يفرض اختيار الملف وموافقة المستخدم. الربط المباشر مدعوم أساساً في Chrome وEdge على الحاسوب. يحتفظ التطبيق بنسخة عمل محلية في المتصفح أيضاً. فتح الصفحة على جهاز آخر أو هاتف لا يشارك تلقائياً نفس البيانات أو ملف Excel؛ يلزم نقل ملف Excel/النسخة الاحتياطية أو استضافة مشتركة مناسبة.

## البنية
- `index.html` — الصفحة الرئيسية وواجهات إدخال البيانات.
- `assets/css/style.css` — التصميم.
- `assets/js/app.js` — إدارة السجلات والحفظ والاستيراد والتصدير.
- `Data/` — ضع هنا ملف Excel الدائم الذي تختاره عند الربط.

مكتبة Excel تُحمّل من CDN؛ يلزم اتصال بالإنترنت عند فتح التطبيق لأول مرة/عند إعادة التحميل لكي تعمل وظائف Excel.
